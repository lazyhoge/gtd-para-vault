# 手順書

## 手順書

* [捕獲（Capture）](capture.md) - 頭に浮かんだこと・会話で出たことを、分類せずに 0-Inbox/ へ入れる手順
* [仕分け（Clarify と Organize）](clarify.md) - 0-Inbox/ の捕獲物を GTD の判定表で仕分け、PARA の入れ物にタスク・Project・知識として置く手順
* [日次の計画](plan-day.md) - 本人が頼んだときに、今日の残りの時間を時間ブロックに割り付ける案を出し、承認したものだけ scheduled に書く手順
* [実績の記録](record-actuals.md) - 本人の「始める」「中断」「終わった」から、タスクの start・intervals・actual・status を埋める手順
* [週次レビュー](weekly-review.md) - エージェントが下ごしらえし、本人が判断する GTD の週次レビュー（Get clear / Get current / Get creative）
