手順の正本は `~/vault/procedures/weekly-review.md` にある。まずそれを読み、そのとおりに進める。
このファイルには手順を書かない（vault 側を唯一の正本にし、Claude Code 以外の実行基盤とも共有するため）。

- vault の規約は `~/vault/CLAUDE.md` に従う
- 下ごしらえでは状態を書き換えない（Project と目標の `actual` の集計だけは例外）。案は案として書き、本人の判断を待つ
- 対話セッションなら、下ごしらえを見せてから本人に判断を聞く（選択肢を出す）
- 定時の非対話の起動なら質問できないので、判断が要るものをすべて案として書き残し、ローカルでコミットして終える（push しない）
